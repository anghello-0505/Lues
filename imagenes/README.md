# Carpeta de imagenes

Guarda aqui las diapositivas de la presentacion.

Reglas:

- Usa nombres consecutivos: `1.png`, `2.png`, `3.png`, etc.
- Si falta un numero, la web dejara de cargar en ese punto.
- Puedes reemplazar las imagenes de ejemplo por tus propios archivos.
- Se recomienda usar imagenes horizontales para aprovechar mejor la pantalla completa.
